Bestimme die Spurpunkte von $E\colon 3x_1 + 2x_2 + 4x_3 = 12$ und zeichne $E$.

Lösung
$x_2 = x_3 = 0$$3x_1 = 12$,  $S_1(4 \mid 0 \mid 0)$ $x_1 = x_3 = 0$$2x_2 = 12$,  $S_2(0 \mid 6 \mid 0)$ $x_1 = x_2 = 0$$4x_3 = 12$,  $S_3(0 \mid 0 \mid 3)$

Eintragen, zum Spurdreieck verbinden – fertig. Es ist nur ein Stück der Ebene.

Besondere Lagen

Fehlt in der Koordinatenform eine Variable, ist ihr Koeffizient 0: Der Normalenvektor steht dann senkrecht auf dieser Achse – die Ebene ist parallel zu ihr. So ist $E\colon x_1 + 2x_3 = 4$ parallel zur $x_2$-Achse. Sie hat nur die Spurpunkte $S_1(4 \mid 0 \mid 0)$ und $S_3(0 \mid 0 \mid 2)$ und wird als Streifen gezeichnet.

Fehlen zwei Variablen, ist die Ebene parallel zu einer Koordinatenebene: $x_3 = 2$ ist parallel zur $x_1x_2$-Ebene. Die Koordinatenebenen selbst sind $x_1 = 0$, $x_2 = 0$ und $x_3 = 0$. Ist $d = 0$, geht die Ebene durch den Ursprung.
