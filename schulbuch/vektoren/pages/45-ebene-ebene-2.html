kein Punkt (parallel)

Merke · Drei Ebenen

Gemeinsame Punkte dreier Ebenen = Lösungen des LGS aus ihren Koordinatengleichungen. Gauß liefert
genau eine Lösung → ein gemeinsamer Schnittpunkt,
einen Parameter → eine gemeinsame Schnittgerade (Ebenenbüschel),
keine Lösung → kein gemeinsamer Punkt: zwei Ebenen parallel oder paarweise Schnitt in drei parallelen Geraden (Prisma).

Beispiel 2 · Ein Schnittpunkt – das LGS aus dem Auftakt

$E_1\colon x_1 + x_2 + x_3 = 6$, $\;E_2\colon x_1 - x_2 + x_3 = 2$, $\;E_3\colon 2x_1 + x_2 - x_3 = 1$.

(I) − (II)$2x_2 = 4$,  also $x_2 = 2$ (I) + (III)$3x_1 + 2x_2 = 7$,  also $x_1 = 1$;  aus (I): $x_3 = 3$ ErgebnisDie drei Ebenen schneiden sich im Punkt $S(1 \mid 2 \mid 3)$.
Beispiel 3 · Gerade oder Prisma?

Ersetze $E_3$ durch $F\colon 2x_1 + 2x_3 = c$. Addiert man (I) und (II), entsteht $2x_1 + 2x_3 = 8$. Für $c = 8$ ist (III) überflüssig: Es bleiben 2 Gleichungen, die Lösung ist die Gerade $x_2 = 2$, $x_1 = 4 - t$, $x_3 = t$. Für $c = 5$ folgt der Widerspruch $8 = 5$: kein gemeinsamer Punkt. Da keine zwei Normalenvektoren kollinear sind, ist das der Prisma-Fall.
